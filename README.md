# Family Archive — Windows Releases

This repository will host official downloadable Family Archive installers and release notes.

**No family photographs, genealogy records, SQLite databases or other personal data belong in this repository.** Application source lives in the private `Eltallin/FamilyArchive` repository.

There are no verified, signed installers published yet. GitHub Actions can produce Windows test builds, but Smart App Control may block unfamiliar unsigned executables. In-app automatic installation will be allowed only for verified, trusted signed installers.

Check the [Releases](https://github.com/Eltallin/FamilyArchive-Releases/releases) page for future versions.
